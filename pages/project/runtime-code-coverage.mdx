`Internal tool | Optus | May 2025`

- Designed and developed an internal tool to end-to-end automate runtime code coverage collection for Java microservices across 4 OpenShift (OCP) clusters, scaling to 100+ services
- Built a centralized Web UI for coverage configuration, on-demand execution, and historical report tracking
- Integrated runtime coverage reports with SonarQube to deliver clear visualization of untested code paths
- Elevated average code coverage from 50% to 80% during live ST/SIT execution cycles, directly improving testing effectiveness and strengthening release confidence
