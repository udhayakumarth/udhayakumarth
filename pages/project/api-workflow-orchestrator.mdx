`Internal tool | Optus | Sep 2025`

- Designed and developed a Java-based CLI tool to orchestrate complex API workflows for telecom onboarding flows (Broadband and Mobile)
- Architected a modular workflow engine with reusable request templates and configurable pre/post execution hooks, enabling rapid composition of multi-step test scenarios
- Implemented centralized context management to handle request/response transformation and data mapping across chained API calls
- Reduced manual testing time from ~20 minutes per run to a few seconds, significantly accelerating release cycle efficiency
